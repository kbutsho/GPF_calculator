# PF Calculator — বছর সমাপনী হিসাব

প্রভিডেন্ট ফান্ডের **জুলাই–জুন অর্থবছরের** প্রফিট ও ক্লোজিং ব্যালেন্স হিসাব করার অ্যাপ।
ওপেনিং ব্যালেন্স, স্ল্যাব রেট, প্রতি মাসের চাঁদা — সব নিজে ইনপুট দেওয়া যায়, আর প্রতিটি
বছর MongoDB-তে সংরক্ষিত থাকে।

## চালানো

```bash
npm install
npm run dev      # http://localhost:3100
```

`.env.local` ফাইলে শুধু একটাই ভ্যারিয়েবল লাগে:

```
MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>.mongodb.net/pf_calculator?retryWrites=true&w=majority&appName=Cluster0
```

## হিসাবের নিয়ম

প্রফিট দুই ভাগে হিসাব হয়, কারণ ওপেনিং ব্যালেন্স পুরো ১২ মাস ফান্ডে থাকে কিন্তু
এ বছরের চাঁদা প্রতি মাসে আলাদা আলাদা ঢোকে।

**পার্ট ১ — ওপেনিং ব্যালেন্স (স্ল্যাব নিয়ম)**

পুরো টাকার উপর এক রেট নয়। টাকাকে ধাপে ধাপে ভাগ করে প্রতি ধাপে আলাদা রেট:

```
প্রথম ১৫ লাখ   @ 13%
পরের ১৫ লাখ    @ 12%
বাকি যা আছে    @ 11%
```

**পার্ট ২ — এ বছরের জমা (মাস অনুপাতে)**

```
প্রফিট = জমা × রেট × (কত মাস বসেছে ÷ 12)
```

জুলাইয়ের টাকা ১২ মাস বসে, জুনের টাকা ১ মাস। রেট ডিফল্টে **সর্বোচ্চ স্ল্যাব রেট** —
অর্থাৎ ব্যালেন্স যে ধাপে গিয়ে ঠেকেছে সেই রেট, কারণ নতুন প্রতিটি টাকা ওখানেই বসে।

**মোট**

```
Profit         = পার্ট ১ + পার্ট ২
Closing Balance = Opening + Subscription + Refund − Withdrawal + Profit
```

**পয়সার নিয়ম:** ডিফল্ট **ট্রাংকেট** — পয়সার পরের অংশ ফেলে দেওয়া হয় (রাউন্ড নয়),
কারণ অফিসিয়াল স্টেটমেন্ট এভাবেই করে। টেবিলের প্রতিটি লাইন দেখানোর সময় রাউন্ড করা হয়
যাতে যোগফল মিলে যায়, কিন্তু মোট হিসাব হয় পূর্ণ নির্ভুলতায় করে শেষে একবার কেটে।

## ফিচার

| ফিচার | কী করে |
|---|---|
| লাইভ হিসাব | টাইপ করার সাথে সাথেই ডান পাশে ফলাফল, সেভ না করলেও |
| স্ল্যাব এডিটর | ধাপ যোগ/বাদ, প্রতি ধাপের পরিমাণ ও রেট নিজে বসানো |
| রেট মোড | স্বয়ংক্রিয় (সর্বোচ্চ স্ল্যাব) অথবা নিজে লেখা রেট (যেমন ৮.৫%) |
| পদ্ধতি | মাস অনুপাতে / ফ্ল্যাট / অর্ধ-বছর — পাশাপাশি তুলনাও দেখা যায় |
| বাল্ক ফিল | এক ঘরে অঙ্ক লিখে ১২ মাসে একসাথে বসানো |
| রিফান্ড ও উত্তোলন | প্রতি মাসে আলাদা, উত্তোলনের প্রফিট বাদ যায় |
| **রিপোর্ট মিলানো** | স্টেটমেন্টের Profit লিখলে মিলছে কিনা বলে; না মিললে **কোন রেটে মিলবে** সেটা বের করে দেয় |
| পরের বছর | এক ক্লিকে ক্লোজিং ব্যালেন্সকে পরের বছরের ওপেনিং বানিয়ে নতুন শিট |
| প্রিন্ট | পরিষ্কার প্রিন্ট ভিউ, নেভিগেশন বাদ দিয়ে |
| ব্যাখ্যা | প্রতিটি হিসাব ধাপে ধাপে টেবিল ও ফর্মুলাসহ পেজের নিচে |

## স্ট্যাক

Next.js 16 (App Router, JS) • Mongoose • Bootstrap 5 + Bootstrap Icons •
react-toastify • SweetAlert2

## গঠন

```
app/
├── page.js                  # সংরক্ষিত বছরের তালিকা + সারাংশ
├── year/new/page.js         # নতুন হিসাব (?carry=1 হলে আগের বছর থেকে আসা ডেটা)
├── year/[id]/page.js        # সংরক্ষিত বছর খোলা/এডিট
└── api/years/               # GET তালিকা, POST, এবং [id]-এ GET/PUT/DELETE
lib/
├── calc.js                  # পুরো হিসাবের ইঞ্জিন (pure, কোনো React/DB নির্ভরতা নেই)
├── constants.js             # অর্থবছরের মাস, ডিফল্ট স্ল্যাব, মোড ও লেবেল
├── payload.js               # ইনপুট normalize + inline validation
└── mongodb.js               # ক্যাশড কানেকশন হেল্পার
models/PfYear.js             # pf_years কালেকশন
components/
├── YearForm.js              # ইনপুট ফর্ম + লাইভ ফলাফল প্যানেল
├── Breakdown.js             # "হিসাবটা কীভাবে হলো" — ধাপে ধাপে ব্যাখ্যা
└── NumberField.js
```

`lib/calc.js` ইচ্ছে করেই React ও ডেটাবেজ থেকে আলাদা রাখা হয়েছে — সার্ভার, ক্লায়েন্ট,
দুই জায়গাতেই একই ফাংশন চলে, তাই তালিকা পেজ আর ফর্ম কখনো ভিন্ন ফল দেয় না।
